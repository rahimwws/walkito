# Spec: Progress screen — path

## Design tokens (from reference)

```
Screen background     #000000
Card                  #131313, radius 28
Card border           #2A2A2A, 1px
Pill inactive         #1C1C1E
Pill active           #2C2C2E, white text
Primary button        #FFFFFF, text #000000, radius 32
Text primary          #FFFFFF
Text secondary        #8E8E93
Divider               #1F1F1F

Accents (icons and active node only):
Orange                #FF7A29
Blue                  #2F80ED
Red                   #FF4D3D
Green (success)       #32D74B
```

**Type scale:**
```
Hero number           64–72 pt, Bold, tracking -2%
Section title         28 pt, Bold
Subtitle              17 pt, Regular, secondary
Node label            13 pt, Medium
Pill                  17 pt, Medium
```

Rule: **color carries meaning, never decoration.** Base palette is monochrome. Accent appears only on the active node and metric icons.

---

## Screen structure, top to bottom

### 1. Header (fixed, does not scroll)

Left: `Progress` — 34 pt Bold.
Right: pill with flame icon and `12 days` + circular avatar 44 px.

Height 64 px, background #000. A #1F1F1F hairline appears under it on scroll.

### 2. Segmented control

Three pills: `Week` · `Program` · `All`
Height 48 px. No horizontal scroll needed — three fit.
`Program` is active by default.

Switching changes the **zoom level of the path**, not the content: `Week` shows 7 nodes large, `Program` shows the current 14-node block, `All` shows the whole program as small nodes.

### 3. Stats block

Follows the reference layout — large number on the left, labels around it.

```
You've completed
14 / 56 days

[icon] Lv3 calf   [icon] 12% asymmetry   [icon] Share
```

Hero number 64 pt, denominator gray 24 pt. Metric row — colored icons, white text 17 pt.

Block height ~180 px.

---

## 4. The path — core of the screen

### Geometry

Vertical ribbon, scrollable. Nodes zigzag with ±64 px amplitude from center, 96 px vertical step.

Position formula: `x = centerX + sin(index × 0.9) × 64`

Between nodes — connector line: dashed #2A2A2A at 3 px for upcoming, solid #FFFFFF for completed.

### Node sizes

| Type | Diameter | When |
|---|---|---|
| Regular day | 64 px | Every program day |
| Checkpoint (retest) | 88 px | Every 14th node |
| Block finish | 96 px | End of program block |

### Node states

**Completed (green day):**
Fill #FFFFFF, black checkmark inside. No border.

**Completed in unload mode:**
Fill #1C1C1E, border #FFFFFF 2px, white rest icon inside (crescent or leaf). Critical: **visually equal to a completed day**, must not read as a miss.

**Today (active):**
Fill #FF7A29, white session-type icon inside. Pulsing ring around it — #FF7A29 at 0.25 opacity, 2 s loop, `transform: scale(1 → 1.15)`, `opacity: 0.25 → 0`.

**Upcoming:**
Fill #131313, border #2A2A2A 2px, gray day number inside.

**Missed:**
Fill #131313, border #2A2A2A, gray icon inside. **Not red.** A miss is never punished visually.

**Checkpoint (retest):**
88 px, fill #131313, 3px border. If available — border #FF7A29 with pulse. If completed — fill #FFFFFF, black delta number inside: `+8`.

### Labels

Under the active node — 13 pt Medium white: `Today · 3 min`.
Under checkpoints — `Retest`.
No other labels. The path needs air.

### Block dividers

Every 14 nodes — a full-width divider:
```
────────  Block 2 · Strengthen  ────────
```
13 pt, secondary, centered, #1F1F1F lines on both sides.

### Auto-scroll

On screen open, the path scrolls so the **active node sits at 40% of screen height from the top**. 400 ms, easeOut. Not all the way to the top — the user should see completed work behind them.

## 5. Floating bottom card

Pinned above the tab bar, does not scroll. Matches the reference card:
fill #131313, radius 28, border #2A2A2A, padding 20.

Contents:
```
Today
Recovery · 3 min

[ Start ]   ← white button, full width, height 60
```

If the session is done — the button is replaced by a centered row: checkmark + `Done` + small `Come back tomorrow`.

If a retest is due — the whole card changes:
```
Time to check your progress

```

## 6. Tab bar

Floating pill centered at the bottom, as in the reference. Fill #1C1C1E, radius 32, width ~280, 24 px bottom inset.
Two items: `Home` and `Progress`. Active — #2C2C2E backing with white icon and label. Inactive — gray.

## Zone levels — where they live

Important constraint, and it must not be broken: **levels must never advance alongside the path.**

Path = days. Levels = test results. If they move together, the user loses the ability to tell real progress from inflation.

Solution: **levels live inside checkpoints.** Between retests they don't change anywhere, including the stats block. Tapping a completed checkpoint opens a sheet:

```
Retest · Day 14

Calf         11 → 19    Lv2 → Lv3
Arch         18s → 24s  Lv2
Balance      8s → 14s   Lv2 → Lv3
Symmetry     34% → 21%  Lv1 → Lv2

[ Share ]
```

This is the only place levels are shown in full.

---

## Interactions

| Action | Result |
|---|---|
| Tap completed node | Sheet: date, what was done, pain that day |
| Tap active node | Same as the Start button |
| Tap upcoming node | Preview sheet: which exercises are coming, no way to start early |
| Tap checkpoint (completed) | Retest table sheet + share |
| Tap checkpoint (available) | Retest flow |
| Long press | Nothing. Don't overbuild |

---

## Animation

**Session complete → return to path:**
The active node fills white with a checkmark, 300 ms, `spring(damping: 0.7)`. The connector to the next node fills left to right over 400 ms. The next node lights orange after a 200 ms delay.

**Level up at a checkpoint:**
Node scales to 1.2× and back, delta number fades in. 600 ms total. Haptic `.success`.

Nothing else animates. The path is not a carnival.

---

## Deliberately NOT building

- **No hearts or lives.** Works for Duolingo; here it pushes people to train through pain.
- **No locks on upcoming nodes.** The path is linear by date, not by unlock. A lock implies you could go faster — and in rehab you can't.
- **No branching map.** One line, one direction.
- **No points or currency.** The only numbers in this product are test results and pain.
- **Missed days are never red.** Gray and uncheckmarked at most.
